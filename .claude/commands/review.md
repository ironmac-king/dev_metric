# 代码审查命令

## 用途
对代码变更进行全面的安全性和质量审查。

## 执行方式
```
/project:review [范围]
```

## 审查范围
- `[all]` - 全部代码审查
- `[ai]` - AI服务代码审查
- `[go]` - Go后端代码审查
- `[web]` - 前端代码审查

## 审查要点

### 1. 安全性检查
- [ ] SQL注入风险（参数化查询）
- [ ] XSS漏洞（输入输出转义）
- [ ] 敏感信息泄露（日志、错误信息）
- [ ] 权限控制（认证、授权）
- [ ] API安全（CORS、限流）

### 2. 代码质量
- [ ] 错误处理完整性
- [ ] 日志规范
- [ ] 代码重复
- [ ] 命名规范

### 3. 性能检查
- [ ] 数据库查询效率
- [ ] 循环优化
- [ ] 缓存使用

## 输出格式
```markdown
## 代码审查报告

### 问题列表
| 严重程度 | 文件 | 问题描述 | 建议修复 |
|---------|------|---------|---------|
| 🔴 高 | xxx.go | SQL拼接风险 | 使用参数化查询 |
| 🟡 中 | xxx.py | 错误未处理 | 添加try-catch |
```

## 触发条件
- 提交代码前自动触发
- 合并请求时必须审查
