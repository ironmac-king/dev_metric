## 二、十一节点详解

### 节点执行顺序

| 步骤 | 节点 | 类型 | 驱动方式 | 职责 |
|------|------|------|----------|------|
| 1 | `intent_router` | 智能体 | **LLM** | 意图识别（query_value/trend/comparison/ranking/ratio） |
| 2 | `context_enhancer` | 增强 | RAG | 检索历史相似案例，增强上下文 |
| 3 | `mql_generator` | 智能体 | **LLM** | 自然语言 → MQL 结构化查询 |
| 4 | `mql_syntax_validator` | 验证器 | 规则 | MQL JSON Schema 合法性验证 |
| 5 | `mql_semantic_validator` | 验证器 | **LLM** | 指标/维度/时间语义有效性验证 |
| 6 | `sql_generator` | 生成器 | 规则 | MQL → StarRocks SQL |
| 7 | `sql_security_auditor` | 审计器 | 规则 | SQL 安全检查（禁止 DROP/TRUNCATE 等） |
| 8 | `sql_executor` | 执行器 | async IO | 执行 SQL 查询 StarRocks |
| 9 | `data_quality_checker` | 检查器 | 规则 | 空数据/异常值检测 |
| 10 | `result_analyzer` | 智能体 | **LLM** | 分析结果，生成自然语言回答 |
| 11 | `state_manager` | 管理器 | 规则 | 多轮对话状态持久化 |

## 三、MQL Schema

MQL (Metric Query Language) 是连接自然语言和 SQL 的强类型中间表示。

### 核心数据类型

```python
# ai/engine/llm_v2/schema.py

class MQLIntent(str, Enum):
    QUERY_VALUE = "query_value"          # 查指标数值
    QUERY_TREND = "query_trend"         # 查趋势变化
    QUERY_COMPARISON = "query_comparison" # 对比分析
    QUERY_RANKING = "query_ranking"     # 排名分析
    QUERY_RATIO = "query_ratio"         # 占比分析
    QUERY_METADATA = "query_metadata"   # 查业务/技术口径
    GREETING = "greeting"               # 打招呼
    UNKNOWN = "unknown"                 # 无法识别

@dataclass
class MQLMetric:
    code: str           # 指标编号，如 MKI-02-0011
    name: str           # 指标名称，如 总销售额
    table: str          # StarRocks 表名
    field: str          # 字段名
    unit: str           # 单位

@dataclass
class MQLDimension:
    type: str           # 维度类型（店铺/平台/渠道/品类等）
    column: str         # 数据库列名
    value: Any          # 过滤值

@dataclass
class TimeRange:
    type: TimeType      # DATE_RANGE / RELATIVE / ABSOLUTE_MONTH
    start: str          # 开始日期 (YYYY-MM-DD)
    end: str            # 结束日期
    original: str       # 原始表达，如 近30天

@dataclass
class MQLSchema:
    version: str = "1.0"
    session_id: str
    intent: MQLIntent
    confidence: float = 0.7
    metric: Optional[MQLMetric] = None
    time: Optional[TimeRange] = None
    dimensions: List[MQLDimension] = field(default_factory=list)
    filters: List[MQLFilter] = field(default_factory=list)
    comparison: Optional[ComparisonSpec] = None
    order_by: Optional[OrderBySpec] = None
```

## 四、多轮对话机制

### 上下文继承

```
用户: "广告转化率是多少"
  → intent_router: query_value
  → mql_generator: MQL(intent=query_value, metric=广告转化率)
  → sql_executor: 返回空数据
  → result_analyzer: "当前暂无数据"
  → state_manager: 保存 MQL 到 v2_session_mql[session_id]

用户: "环比呢" （短追问）
  → intent_router: 检测到 < 10 字符 + 包含"环比"
  → 继承上轮 MQL(intent=query_comparison)
  → 复用 metric, time, dimensions
  → 继续执行后续节点
```

### Checkpoint 回退

V2State 通过 LangGraph MemorySaver 支持状态回退：

```python
# ai/engine/llm_v2/graph.py
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
graph = create_v2_graph(checkpointer=checkpointer)
```

## 五、API 接口

### POST /api/v1/llm-ask/v2

**请求体**：
```json
{
  "question": "广告转化率是多少",
  "session_id": "可选",
  "stream": true
}
```

**响应（SSE 流式）**：
- `event: chunk` - 文本片段
- `event: chart` - 图表数据 `{"charts": [...], "markdown": "..."}`
- `event: thinking` - 思考步骤 `{"steps": [...], "totalTime": 1234}`
- `event: done` - 完成

```
┌─────────────────────────────────────────────────────┐
│                   查询请求                           │
└─────────────────────┬───────────────────────────────┘
                      ▼
         ┌────────────────────────┐
         │   L1 内存缓存 (LRU)     │

                      ▼ miss
         ┌────────────────────────┐
         │   L2 Redis 缓存        │
         │   7天 / 1 小时 TTL     │ ◄── < 10ms

         ┌────────────────────────┐

```

## 九、已删除：LLM.V1

LLM.V1（八节点架构）已于 2026-04-21 删除，不再维护。

**原 LLM.V1 节点**：LU → SF → SQL → CK → EX → RV → CHART → RS

**删除原因**：
- LLM.V2 提供更完整的验证链路（语法+语义双重验证）
- LLM.V2 支持 Checkpoint 状态回退
- LLM.V2 内置 RAG 和多级缓存
